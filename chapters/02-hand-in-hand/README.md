# 第二章 手拉手模型

面向初二、初三培优学生，从两道原题归纳“手拉脚、脚拉脚如何补成手拉手”。题目和集中解析分开，每题保留两种方法；总结同向旋转、倍长补直角及中点搬运。

    python scripts/build.py --target book

六幅重绘图同时保留 PNG、SVG 和 TikZ，数值长度不重复写在图上。原始视频、字幕、截图 Word/PDF、提取图片和视频帧仅保留本地，均已排除版本管理。
